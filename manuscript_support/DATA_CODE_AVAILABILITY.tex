\section*{Data availability statement}

The hyperspectral datasets used in this study are publicly available from the
original providers identified in the manuscript and reproducibility package.
The repository does not redistribute the original hyperspectral cubes or
reference maps. Dataset acquisition instructions, expected filenames, and
preprocessing details are provided with the software. Derived Graph-RMS
partitions, experimental configurations, evaluation summaries, and numerical
results supporting the tables and figures are archived in the public Graph-RMS
reproducibility record at
\url{https://doi.org/10.5281/zenodo.21876448}.

\section*{Code availability statement}

The Graph-RMS source code, frozen configurations, analysis scripts, curated
derived outputs, and environment records are available from
\url{https://github.com/Simhaatt/Graph-RMS} and the corresponding archived
Zenodo record at \url{https://doi.org/10.5281/zenodo.21876448}. The cited
software version is release \texttt{v1.0.0}.
