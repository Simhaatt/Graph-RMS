\section*{Data availability statement}

The hyperspectral datasets used in this study are publicly available from the
original providers identified in the manuscript and reproducibility package.
The repository does not redistribute the original hyperspectral cubes or
reference maps. Dataset acquisition instructions, expected filenames, and
preprocessing details are provided with the software. Derived Graph-RMS
